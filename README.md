# ESP32 Home Automation

Practical ESP32 automation examples for IoT projects and self-hosted environments.

## Features

* MQTT integration
* Relay automation
* Sensor monitoring
* WiFi device control
* Home Assistant compatibility
* Docker-friendly backend examples

## Technologies

* ESP32
* MQTT
* Python
* Home Assistant
* Node-RED

## Goals

This repository contains practical automation workflows and embedded system experiments intended for makers, developers, and self-hosting enthusiasts.

More examples and integrations will be added regularly.
